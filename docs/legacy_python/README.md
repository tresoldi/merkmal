# Legacy Python Material

These tutorials, notebooks, and scripts were written for the pre-C Python
implementation. They are kept as reference material while the native C library
and Python wrapper mature, but they are not accurate user documentation for the
current package and may reference modules that no longer exist in the active
tree.
