# 0002. Unicode normalization is compiled in

## Context

Normalization (NFC/NFD) used to come from libutf8proc when it was installed
and from a smaller built-in fallback when it was not. The two returned
different strings for some input under the same version number, so a result
depended on how the library happened to be built.

## Decision

NFC and NFD are implemented in `src/unicode_norm.c` from tables generated by
`tools/generate_unicode_data.py`, and every build uses them. utf8proc is not a
dependency of the library. When present, it is used only as an independent
oracle by the `unicode` test; `MERKMAL_REQUIRE_UTF8PROC=ON` makes CI fail
rather than skip that comparison.

## Consequences

- Every build of one commit normalizes identically; `mk_unicode_version()`
  says which Unicode version the tables carry.
- Moving to a new Unicode version is a data change: regenerate the tables with
  an interpreter of that version and run the oracle against a matching
  utf8proc (docs/development/release-policy.md).
- The library has no runtime dependencies.
